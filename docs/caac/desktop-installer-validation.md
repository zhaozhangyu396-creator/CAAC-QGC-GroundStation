# 飞虎无人机地面站系统 Windows 验证版

应用源提交：`89a919872384dd5432bde8d483f658922d05ea74`；分支：`phase3/caac-route-geometry`。
用户已确认主界面、菜单、偏好和计算器的样式。本地完整回归、Windows Debug 和 Release 安装包使用同一应用源提交。

## 本次功能

- 飞行与计划合并为默认主界面，规划四个功能栏默认收起，再次单击图标可收起。左侧任务详情、飞行数据、地图设置、计算器、清除航迹纵向排列，统一深色方形按钮；小窗口支持滚动。右侧全局设置、相对坐标编辑、模板、航点设置使用相同样式，取消整块背景填充。统计数据默认关闭。
- 顶栏保留齿轮设置，移除就绪栏与渐变背景；解锁／上锁、消息、传感器状态独立显示。飞行模式使用协调的紧凑选择界面。飞行设置展开两排八项操作，包含更改航速；飞行计时使用无人机原生 flightTime，解锁开始、上锁停止。连接状态实时显示已连接／未连接，单击进入设置－连接。
- 左下角定位、撤销、重做、地图放大、地图缩小工具条缩为原尺寸的一半。定位图标单击将地图居中到起飞点，双击将地图居中到无人机，均保持起飞点与航点坐标不变。撤销支持 Ctrl+Z；移除原四按钮横排，旋转与相对坐标功能通过设置栏操作。
- 齿轮菜单采用分类侧栏，模拟与统计数据移入其中。偏好提供航点绘制、地面站 UI、飞行参数三页：水平／垂直／角度／中垂线吸附、吸附角度、深浅主题，以及实际可用飞控参数的读取和写入；参数沿用原 Fact 的单位和范围，未连接或不支持时禁用。绘制评分按用户要求不加入。
- 独立计算器包含风向角度、24 小时时间角度、六种三角函数的角度／弧度计算、直角三角形计算与示意图；结果可复制，自动补全数值支持重新计算，非法或过度约束输入会提示。
- 拖动航点支持正北／东／南／西、角度和邻点对齐、中垂线与垂直辅助线，并显示真实航段夹角。鼠标接近航段时自动捕捉，在中点显示＋，包括起飞点与首个航点、指定起始点和返回起飞点的可编辑航段。取消航线方向箭头，保留距离、方位角和夹角。
- 起飞点支持右键功能菜单和航点相对关系设置；计划起飞点海拔自动填入可用的当前起飞点海拔／地面高程，保留手动输入。航点属性补全高度、水平／垂直速度、变高方式、停留时间、方位角、前点及此点夹角、距离、机头方向与转弯设置，几何修改支持撤销和重做。
- 全局旋转、平移合并为旋转平移，提供整条航线拖拽、两点定向旋转、参考点坐标平移、八方向定距移动、围绕航点旋转及包含 H 点选项。速度与新航点高度可同步已设普通航点，并保留各点高度基准。打开、保存、上传、清空等航线文件功能移入航点设置栏；删除模拟风场菜单。
- 仪表改为外圈航向罗盘与内圈姿态仪，支持缩放与左键拖动，下方显示八项飞行数据。底部居中显示电池、飞行高度、距家、真实航向、水平／垂直速度和目标距离；航向图标随真实航向转动。应急界面下方显示高度、速度、航向角。清除航迹只清除活动无人机的已飞轨迹，规划任务保留，后续轨迹继续记录。
- 模拟与上传继续验证起始点、返回点、闭合、有限／无限循环、实际显示编号、重复读取与上传、航速和航高变更、转弯与变高行为、前飞姿态和应急恢复。保留中文品牌、模式名称、默认桌面快捷方式和现有安装／升级／卸载验证。

航点的垂直速度、变高与转弯元数据用于模拟；原生任务字段沿用原实现。模拟和自动化检查不表示实机飞行已验收。
