# 飞虎无人机地面站系统 Windows 验证版

安装包源提交：`71c307ef1225da59d52cd2c70d1434ff0d0a56ed`，分支 `phase3/caac-route-geometry`。

## 本次功能

- 航点列表各行提供编辑、删除；底部提供读取航点、上传航点。读取覆盖未保存规划前确认，连接未就绪或传输中禁用。
- 左键航点打开方位角、距离、微调和删除；上下键每次 ±0.1°，左右键每次 ±0.1 米。右键提供辅助作图、坐标轴、起飞点操作、删除、指点飞行和航线反向。
- 重叠航点悬停显示编号；加载航线后修改模板朝向实时旋转，确认可撤销，取消恢复。预览期间先确认或取消，再保存或上传。
- 飞行操作横向排列于左上角，提供开始／继续、暂停、跳转航点、航点高度修改；仪表增加中文标注和航向角。
- 全局高级模拟设置支持转弯、爬升、循环、结束行为及风场；计划界面上传并执行模拟任务，重启清零四向里程。
- 菜单入口为齿轮，设置术语使用“无人机”“首选机型”“访问令牌”；移除帮助、PX4 日志传输及远程 ID 设置入口。
- 窗口和安装程序使用公司名称与 Logo。默认和静默安装自动生成公司桌面快捷方式；升级更新目标路径，卸载清理。

## 安装后验证

1. 解压下载的 ZIP，打开 `build` 文件夹，运行 `QGroundControl-installer-AMD64.exe`。安装后桌面应出现“飞虎无人机地面站系统”，双击启动，确认公司图标与窗口名称。
2. 计划界面打开航点列表，检查各行编辑／删除和底部读取／上传；连接就绪后再验证任务传输。通过左键属性和右键菜单检查相应航点操作。
3. 启用微调，检查上下键角度和左右键距离每次变化 0.1；加载模板后调整朝向，检查预览、取消、确认和撤销。
4. 在计划界面的“模拟”窗口上传并执行航线，查看飞行页中文仪表、航向角与任务控制；重新开始后检查四向里程归零。

内置模拟为隔离的运动学训练，不属于 PX4 SITL，不代替飞控、动力学或实机验证。协调转弯仍沿航段连线移动。模拟支持任务内起飞与结束返航，未实现飞行页手动起飞／降落／返航按钮的模拟运动。UOM、教学／考试、遥控通道、故障模型和外部 SITL 不在本次交付范围。详细行为见 [模拟与飞行控制](simulation-and-flight-controls.md)。
