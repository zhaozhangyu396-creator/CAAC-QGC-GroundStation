# 飞虎无人机地面站系统 Windows 验证版

安装包源提交：`1d1b507f368594028977cc169b339425382e6b6e`，分支 `phase3/caac-route-geometry`。

## 本次功能

- 飞行界面左上角固定两排七项功能：开始航线、暂停航线、一键起飞、一键返航、跳转航点、更改航高、模拟应急。与右侧功能栏顶排对齐、图标等大、位置对称，无横向滚动；移除抓手和其他顶层操作。
- “更改航高”独立于跳转航点，可修改航点高度并上传，也可更改当前飞行高度；圆形姿态仪显示蓝色天空、绿色地面及实时俯仰、滚转和航向。
- 规划界面点击“模拟”即连接虚拟无人机；编辑并上传后进入飞行界面，通过功能栏手动起飞、开始／暂停航线、跳转、调整高度和返航。模拟应急隐藏地图及实时位置，只显示姿态信息和控制区；可恢复显示或断开模拟。
- 航点列表每行提供编辑／删除，底部提供读取／上传。左键显示属性，右键提供辅助作图、起飞点、删除、指点飞行和航线反向；重叠航点悬停显示全部编号。
- 微调上下键每次 ±0.01°，左右键每次 ±0.01 米，开关不改变窗口位置；辅助作图输入字体加深。坐标轴缩小并标注 N/S/W/E，支持左键拖动和右键删除。
- 已加载模板修改朝向可同步旋转预览、确认／取消和撤销；起飞点与首航点连线，相对坐标支持从已知航点设置起飞点或降落点；红色地形碰撞航线显示“真高过低，请调整航点高度。”
- 全局设置保留已有功能并按带标题、边框及蓝色分隔线的类别组织，补充模拟水平速度及地图编辑／辅助作图管理。移除指定说明文字，使用齿轮入口及公司蓝色渐变，配置／分析／设置页不显示公司 Logo，遥测保留中文并移除装饰图标。
- 新安装默认缩放 120%；已有缩放设置升级时保留。安装自动生成“飞虎无人机地面站系统”桌面快捷方式，更换目录升级会更新其目标、工作目录及图标，卸载时移除。
