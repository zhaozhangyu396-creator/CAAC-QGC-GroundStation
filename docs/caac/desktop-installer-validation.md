# 飞虎无人机地面站系统 Windows 验证版

安装包及本地完整回归的应用源提交为 `f93ba65c9e7e2f96a6666ab0ba1ca0061ad13afd`，分支 `phase3/caac-route-geometry`。Windows Debug 与 Release 回归均使用同一应用源提交。GUI 协议时序测试钩子在 Release 中编译排除。

## 本次功能

- 七个飞行控制紧跟飞行模式，位于原高度顶部同一横排，圆心对齐顶栏水平中轴：一键起飞、一键返航、开始航线、暂停航线、跳转航点、更改航高、模拟应急。左键双击执行，单击不发命令；跳转和航高独立输入参数，取消多余滑动确认。
- 更改航高支持单个或全部普通航点；模拟执行中自动暂停、上传成功后继续原进度，实际飞行高度会响应；当前飞行航高可独立输入。右侧任务详情／飞行数据／地图设置互斥切换。
- 模拟电池保持 100%，移除地图“模拟飞行”文字；姿态仪的红箭头、俯仰和横滚随模拟运动变化。模拟应急黑屏隐藏地图及实时位置，显示放大姿态仪和控制区。
- 规划栏“模拟”在连接后改为“取消模拟”，点击断开并保留航线，不额外弹出断开计划确认；可重新进入。上传后的航点显示编号与规划一致。闭合航线包含末号到首号的连线；从所选起始点完成整圈后回到该点，预览与执行一致。起飞只执行一次、总执行次数包含首轮，循环衔接不重复停留。
- 相对坐标设置起飞点或降落点时可选择方位角／夹角；起飞点与一号航点连线，红色地形碰撞航迹提示“真高过低，请调整航点高度。”计划起飞点经纬度增加十进制度与度分秒换算，保留未编辑坐标的精度。
- 重叠航点提示按实际经纬度重合判断，7.1 米等相邻点不会误提示重叠。航点列表支持复选框、全选／取消全选和批量删除，保留计划起飞点及特殊指令，支持一次撤销／重做。航点快捷窗口在“删除”上方增加“确认”，应用方位角和距离并关闭窗口；角度与距离微调均为 0.01。
- A/B 测量直接依次左键选 A、B 点；长按左键拖动点位，实时显示距离和真北方位角；右键 A 或 B 才打开设置窗口，测量不改变任务。
- 全局设置移除独立“模拟飞行”和“起飞与飞行速度”栏：保存模拟设置位于模拟风场，起飞高度／水平速度位于基础设置。新安装默认 120%、PX4、多旋翼和公制，语音播报默认关闭，取消首次偏好弹窗；保留用户已有自定义设置。设置齿轮、公司蓝色渐变、中文遥测及页面 Logo 调整保留。
- 安装自动生成中文桌面快捷方式，更换目录升级更新目标、工作目录和图标，卸载时清理。

- **本轮文字、模式与顶部工具栏**：安家于此改为返回于此，没有新车信息改为没有最新消息；八个 PX4 飞行模式按用户指定译名显示，连接后重新枚举保留中文，菜单移除 Offboard、Precision Landing 和 MockLink Mode；围栏六个选项按用户译名显示，参数值保持原定义。七个飞行控制紧跟任务模式位于原高度顶部同一横排，顺序为一键起飞、一键返航、开始航线、暂停航线、跳转航点、更改航高、模拟应急；随窗口宽度缩小图标，避免横向滚动。

- 新建模拟默认位置为纬度 25.137898058569604、经度 102.7212769885262，保留已有规划起飞点。规划中地面模拟无人机图标随起飞点实时移动，居中覆盖，不拦截起飞点拖动。
- 相对坐标连续添加后，基准点与插入位置均自动跟随最新航点，刷新列表时保留选择；失败不改变选择。重叠航点优先显示编号最大的点。
- 修复 A/B 左键长按拖动，禁止地图抢占拖动；右键窗口不再额外弹出英文文本菜单，清除测量后自动关闭窗口。“返回航点列表”改为“退出高级任务设置”。计划起飞点可直接拖动，保留海拔并支持撤销。
- 闭合、循环次数、起始点、返回点和坐标修改在规划地图实时预览，保存前不改变源任务；保存后保持预览。末点至首点闭合，循环衔接与上传执行顺序核对。
- 等高前飞根据沿机头方向的速度估算低头倾角，速度越快倾角越大；转弯横滚继续变化，暂停、悬停恢复水平。内置运动学估算，不代表真实机体动力学。

- 修复相邻航点扩大点击区域截获起飞点操作的问题：点击或拖动时由距离鼠标最近的可见点处理；真正重合仍保留大编号优先。

- 航线旋转默认打开两点定向旋转，并将其放在下拉菜单首项；按角度旋转保持可用。
- 起飞点使用蓝底白边 H 图标，左键可选择相对航点、编辑方位角与距离、开启微调，保留海拔和撤销。
- 应急仪表盘下方居中显示实时相对高度、地速与航向角，沿用单位设置。
- 鼠标悬停在可编辑航段上时，中点显示＋；覆盖起飞点到航点 1、航点之间和闭合航段，插入后坐标、编号、航段标注同步更新并支持撤销。
- 起飞点居中将起飞点移到普通航点范围中心，保留海拔和航点位置；右键菜单与左侧按钮行为一致。
- Ctrl+Z 调用规划撤销；起飞点右键提供辅助作图、坐标轴、清空航点、起飞点设置、指点飞行、反向航线，保留起飞点。
- 规划左侧工具栏字号略减，图标和行距随之缩小，保持协调。
- 应急数据行加宽，确保高度、地速、航向角互不重叠，并给模拟控制按钮留出空间。
- 地形路径查询共享原有 10000 点插值上限，长航段按实际间距采样，端点和距离保持正确。

## 验证范围

Qt 单元测试中另有 12 个数据／后端用例按既有规则跳过，包括不适用的 GPS 传输／协议变体及后端未提供多路虚拟摇杆的用例；保留原测试规则并明确记录，本批自定义功能与界面检查全部执行。
