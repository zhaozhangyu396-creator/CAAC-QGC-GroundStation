# 模拟与飞行控制

当前安装包版本 `v5.2.0-dev-233-g80691cac5b`，应用源提交 `80691cac5b6e7e8858e3af26c5f878ef8f666c23`。[下载与验证记录](desktop-installer-validation.md)。

## USB 遥控器与模式映射

1. 以 USB 游戏控制器／摇杆方式接入遥控器，在“无人机设置 → 操纵杆”选择设备，完成横滚、俯仰、偏航、油门校准并启用。应在模拟飞机上锁时校准。
2. 开启内置模拟，上传航线并起飞，进入“模拟应急 → 模拟控制 → USB 遥控器通道映射”。原始通道 CH1 表示第一个 USB 轴，不是飞控接收机 PWM 通道。
3. 选择模式开关的独立轴，设置两段／三段与反向。四个操纵轴不能兼作模式开关。各设备的配置通过原生 Settings Facts 保存；修改配置后须重新启用模式映射。

| 档位 | 默认模式 | 行为 |
| --- | --- | --- |
| 低档 | 自动返航 | 模拟飞机自动返航 |
| 中档 | 姿态模式 | 摇杆控制倾斜、转向和升降，可手动飞回 |
| 高档 | 航线任务 | 继续尚未完成的航线任务 |

启用、重连或修改配置后先识别当前档位，随后拨动开关才切换模式，不会因静止开关位置自动恢复任务。映射仅控制内置模拟飞机。

姿态训练保留水平惯性和风影响，不保持水平位置；油门中位保持高度。它是训练运动模型，不代表真实 PX4 飞控动力学。摇杆输入中断超过 0.5 秒时模拟飞机悬停，不持续执行最后输入；也可在模拟控制中结束接管并悬停。

## 任务与地图操作

- 单击航点选择，左键拖动移动，左键双击打开方位角／距离／微调菜单。右键功能菜单保留。Ctrl+Z 撤销，Ctrl+X 重做；文本框中的 Ctrl+X 保持剪切。
- 新建或移动 H 点后自动应用位置与可用海拔，地形高程返回后同步；手动海拔受保护。此处保存指应用到计划，不会自动写入任务文件或上传。
- 航线正在执行时上传无效，并提示“当前航点任务正在执行，请先暂停当前任务，再上传新航线。”暂停后可重新上传；不会自动暂停或恢复飞行。
- 任务详情显示剩余循环圈数，包含当前圈；暂停时不递减。无限循环显示“无限循环”；重连或遥测缺失导致无法确定时显示未获取数据。
- 统计数据面板左键拖动，右键选择关闭；真高过低报警也可左键拖动。
- 定位图标单击居中到计划起飞点，双击居中到无人机；清除航迹只清除已飞轨迹，保留规划任务。

飞行仪表与状态使用活动无人机遥测，计时按原生 flightTime；上锁红色、解锁绿色。仪表可拖动及缩放，窄窗口会避让右上规划菜单。设置二级菜单再次单击可收起；模拟入口置顶。
