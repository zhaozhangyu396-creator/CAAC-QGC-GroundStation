# 飞虎品牌、模拟飞行与飞行任务操作

本批继续使用原生 QGroundControl 任务模型、Facts、Vehicle 和飞控插件。程序显示名称为“飞虎无人机地面站系统”，公司 Logo 使用用户提供的矢量文件导出；保留原安装标识、设置目录及开源版权信息，以兼容升级。

## 操作路径

- 计划界面四入口：全局设置、相对坐标、模板和航点列表。原任务树仅从全局设置的“高级任务设置”进入。
- 原“兴趣区域”规划按钮改为计划起飞点居中，不新增任务项；飞行界面右侧准心仍为当前飞行器居中。
- 飞行界面七项紧跟飞行模式，位于原高度顶部同一横排：一键起飞、一键返航、开始航线、暂停航线、跳转航点、更改航高、模拟应急。图标略放大并将圆心对齐顶栏水平中轴，随窗口宽度调整尺寸，无横向滚动；删除抓手和其他顶层操作。功能区域左键双击执行，单击不发命令；取消开始／暂停／起飞／返航的滑动确认，跳转与航高仍需选择参数。
- 航点高度可选择下载任务中的单个或全部普通航点，保留各自高度坐标系；保存上传完整任务。模拟执行中自动暂停、等待上传成功后从原进度继续；实机任务执行中须先暂停。当前飞行高度使用独立参数输入，填写后确定即发送命令。等待连接或上传时不能修改，不允许失效窗口在切换飞行器／任务后重新指向另一航点。
- 圆形姿态仪以蓝色天空、绿色地面、白色俯仰／滚转刻度和红色飞机符号呈现实时 Vehicle Facts，底部显示航向；上方红箭头随横滚角转动，天空／地平线与俯仰刻度随姿态变化，缺少数据时显示“未获取”。模拟横滚由转向速率估算，前飞俯仰由沿机头方向的速度估算；等高前飞会低头，暂停与悬停恢复水平，属于运动学训练显示。遥测保留中文标注与数值，去掉装饰图标。
- 全局设置按带边框、标题和蓝色分隔线的类别组织，保留规划／转弯／爬升／循环／风场等设置，补充模拟水平速度和地图编辑／辅助作图管理。新安装默认界面缩放 120%、PX4、多旋翼和公制（距离米、面积平方米、速度米/秒、温度摄氏度），不弹出首次偏好设置，语音播报默认关闭，保留已有自定义设置。
- 计划工具栏点击“模拟”直接虚拟连接无人机，空航线也可连接；进入模拟后按钮改为“取消模拟”，点击断开并保留当前航线，无额外断开确认；在规划界面编辑后上传，收到 ACK 才跳转飞行界面，上传不自动起飞或执行航线。普通航点显示编号沿用规划编号，自动插入的起飞／闭合／循环指令不占用显示编号；跳转仍使用对应飞控任务序号。飞行功能栏控制起飞、航线和返航；删除地图上的“模拟飞行”文字，模拟电池恒为 100%，右侧任务详情／飞行数据／地图设置互斥显示；全局设置移除单独的“模拟飞行”栏，“保存模拟设置”位于“模拟风场”栏，起飞高度和水平速度合并到“基础设置”；“模拟应急”隐藏地图、航迹、飞机位置和位置面板，黑底仅显示位于顶栏下方地图区域中央的放大姿态仪与控制入口，模拟继续运行，退出恢复地图。黑屏中的“模拟控制”提供悬停、原地降落、重启及断开；重新开始回到地面并清零里程，不自动起飞。

## 航点规划交互和菜单

地图左键单击航点打开简洁属性面板：方位角、距离、微调、删除。方位角以真北为 0°、顺时针增加；距离是前一坐标航点至当前航点的水平距离。开启微调后，上／下键改变方位角 ±0.01°，右／左键改变距离 ±0.01 米，最短为 0 米。计划起飞点经纬度支持十进制度与度分秒双向换算，可选择东西经／南北纬，窄面板采用多行输入。只修改位置，保持原高度、速度和命令；关闭微调结束一次可撤销的修改，切换开关保持窗口位置与尺寸。辅助圆半径和辅助线方位角输入文字使用深色。坐标轴缩小并标注 N/S/W/E，可左键拖动、右键删除。相对坐标编辑器支持从任意已知航点通过方位角或夹角设置起飞点或降落点，夹角必须有有效的前一航段；起飞点至第一航点有距离／方位角连线。地形碰撞航迹为红色时显示“真高过低，请调整航点高度。”

右键菜单提供辅助圆（米）、辅助线（真北方位角）、坐标轴、单点删除、确认清空、地图选起飞点、起飞点居中、选中航点更改为起飞点、指点飞行及航线反向。辅助作图是临时地图图层，不写入飞控任务。更改为起飞点使用该航点经纬度并保留计划起飞点海拔，删除原航点；可以撤销。反向保留首尾起飞／降落／返航命令，仅反向中间普通航点；复杂命令或跳转任务拒绝自动反向。指点飞行要求已连接、已起飞且支持引导模式，跳转飞行页使用原生确认流程；内置模拟接受原生 COMMAND_INT／COMMAND_LONG 指点指令，并保持原任务序号。

航点卡片各自提供编辑／删除和复选框，列表支持全选／取消全选、删除选中的几个或全部普通航点。批量删除保留计划起飞点与起飞／降落等特殊指令，支持一次撤销与重做。航点列表底部提供读取／上传按钮，接入原生任务通信、数据完整性和执行状态检查；读取覆盖未保存的规划前确认，未连接或正在传输时禁用。鼠标悬停时按水平坐标重合（1 厘米容差）聚合并列出航点编号，地图缩放不改变重合判断。模板朝向编辑实时旋转已加载航线，从原坐标计算以避免累计误差；确认保存一次撤销，取消恢复原位置。预览期间需先确认／取消再保存或上传，撤销可直接取消预览。

安装完成后自动创建“飞虎无人机地面站系统”桌面快捷方式，使用公司图标；升级更新快捷方式的目标路径，卸载时移除。左上角菜单入口改为齿轮。窗口、快捷方式及安装包使用公司 Logo，名称为“飞虎无人机地面站系统”。中文设置使用“无人机”“首选机型”“访问令牌”；删除帮助、PX4 日志传输和远程 ID 的设置栏入口。

A/B 测量点击后直接依次左键选取 A、B，地图实时显示距离和真北方位角；长按左键拖动点位，右键任一点打开坐标设置窗口，不修改任务。航点快捷窗口在“删除”上方提供“确认”，应用当前方位角和距离后关闭窗口。

## 模拟范围与任务编译

这是内置运动学训练模拟，通过隔离的 MAVLink 连接、真实任务上传及 ACK 接入原生 Vehicle；不属于 PX4 SITL，也不能代替飞控或动力学验证。

支持定点、协调、自适应协调、不转弯四种朝向控制，定点／协调爬升，垂直速度和转向速度，以及水平风场。四种转弯方式控制朝向与移动时序；协调模式仍沿航点连线移动，不模拟真实飞机的倾斜转弯。删除“停止转弯”选项。

保存的设置写入 `.plan` 的 `caac.simulationSettings`，支持撤销／重做。上传时复制航线，编译起飞、闭合、有限／无限 `DO_JUMP` 循环和结束指令，原规划保持不变。闭合航线始终包含末普通航点至首号普通航点的连线，不连接起飞点。指定起始航点后旋转复制的执行顺序，完成整圈再回到起始航点，例如从航点 2 开始为 2→3→…→末号→1→2；预览与执行顺序一致。总执行次数包含首轮，起飞只执行一次；闭合循环衔接处不重复等待同一个起始航点。返回指定航点后悬停，返回起飞点后模拟降落。

模拟目前要求简单任务和全球／相对起飞点高度坐标系，支持读取后重传已有模拟跳转任务；拒绝复杂任务、地形高度及不支持的命令。停止只断开自身模拟连接。存在其他飞行器时拒绝启动；模拟中出现其他飞行器时停止模拟。

这些全局模拟设置不自动映射为实机的转弯、爬升或循环参数。实机任务仍使用对应飞控支持的原生设置和命令；开始／暂停／跳转／高度上传的实机适用范围取决于飞控。UOM、教学／考试、遥控通道、故障模型和外部 SITL 未在本批实现。

## 规划实时预览与地图编辑

新建模拟默认位置为纬度 25.137898058569604、经度 102.7212769885262，保留有效的已有计划起飞点及其海拔；50 米为航点相对高度，不当作地面海拔。规划中的地面模拟红色图标实时跟随计划起飞点，位于其图标上方、拖动操作区下方，不更改实际遥测位置。计划起飞点无需预选即可拖动，临近航点扩大点击区域不会抢占更近点的操作，真正重合仍由大编号处理；保存海拔并支持撤销。相对坐标添加成功后，基准点和插入位置同时跟随最新航点，失败时保持选择。闭合、循环、起始点、返回点和坐标改动立即更新规划地图预览，保存前不修改源任务；保存后继续显示预览。A/B 坐标右键不再叠加英文文本菜单，清除测量同时关闭窗口；高级任务设置退出入口显示为“退出高级任务设置”。

起飞点使用蓝底白边 H 图标；左键可打开相对航点、方位角、距离与微调编辑，确认后应用并关闭。右键起飞点打开辅助作图、坐标轴、清空航点、起飞点设置、指点飞行与航线反向菜单，隐藏起飞点删除项。鼠标移到可编辑航段时，其中点显示＋，包含起飞点至航点 1、普通航段和闭合航段；点击插入航点。起飞点居中将起飞点移动到普通航点范围中心，保留海拔与航点位置，地图视角不变。Ctrl+Z 撤销规划修改，左侧规划图标略缩小。航线旋转默认选择两点定向旋转；应急仪表下方实时显示相对高度、地速和航向角。

仅规划航点 1、2、3 时，勾选闭合航线、起始点选航点 1、总执行次数设 1，预览与执行为 1→2→3→1；多次循环按总执行次数设置。返回点控制循环完成后的去向，不改变闭合航段；存在更多普通航点时，闭合仍连接末号与首号。

## 飞行模式与提示文字

PX4 模式显示为手动模式、姿态模式、手动特技、定高模式、定点模式、保持模式、任务模式、返航模式；动态重新枚举仍保留中文，菜单移除 Offboard、Precision Landing 和 MockLink Mode，保留内部模式编号及未知模式名称。地理围栏行为按原参数值显示为无行为、警告、保持悬停、返航、飞行中止（停止动力输出）、降落。设置返回点按钮改为“返回于此”，无人机消息空态改为“没有最新消息”。
