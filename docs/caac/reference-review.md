## 资料与观察方法

## 用户确认的参考行为（与画面证据分开）

2026-10-10用户直接说明：

| 功能 | 用户确认 | 对设计的处理 |
| --- | --- | --- |
| 相对方向角 | 真北0°、顺时针增加，东90°、南180°、西270° | 统一使用真北测地线方位角，不把屏幕旋转或磁航向混入计算 |
| 角度类型 | 方位角/夹角；前段朝北时90°向西、180°向北、−90°向东；负夹角允许 | 基准点指向前点的反向射线顺时针加夹角；只有起飞点、没有前段时夹角模式不能生成新点 |
| 插入位置 | 新点插在所选航点之后 | 由任务适配层转换成QGC实际插入索引；V1的before-index接口不能直接用显示编号 |
| 单点旋转 | 可以起飞点或已有航点为中心，正角顺时针 | 保留产品需求中的地图空白和精确经纬度中心；中心航点必须精确固定 |
| 两点定向旋转 | A→B连线旋转到指定方向，中心可选任意航点；目标方向真北0°、顺时针增加 | 必须检查变换后的A→B测地方位角，不直接把方位差当作任意中心的旋转结果 |
| 起飞/降落点 | 中心不是起飞点或降落点时，两者随航线移动 | 后一次答复替代此前“起飞点不移动”的概括；区分计划起飞点和飞控实际Home |
| 加点 | 左键双击地图空白处，无需添加模式 | 用户明确选择此方式作为CAAC最终交互，替代原单击要求 |
| 拖图 | 左键长按地图空白区域拖动 | 用户明确选择此方式作为CAAC最终交互，替代原中键要求 |
| 属性编辑 | 右键点航点直接打开属性编辑 | 选点与打开弹窗的事件优先级明确区分 |
| 拖动航点 | 左键按住航点直接拖动 | 航点命中优先于空白拖图；拖动开始/完成/取消接入同一事务层 |
| 撤销/重做 | 支持连续多步撤销；没有redo按钮或快捷键 | CAAC原项目明确要求撤销与恢复，仍实现undo/redo；不把参考软件没有redo当作删除需求 |
| 文件保存 | 只提供.ld格式；保存位置可自行选择桌面 | 不再假设存在明文导出；CAAC采用自有格式/plan转换与可选桌面路径 |

以上为四轮用户确认，不写成采样视频证明。夹角的工程公式为
`normalize360(azimuth(基准点, 前一点) + 夹角)`；这明确符合已确认的90°/180°例子，
以及负90°例子。只有起飞点、没有前段时拒绝夹角生成，不能默认为真北参照。
该答复针对夹角问题，不扩展成方位角模式也不能从起飞点计算新点。

## 航点.ld格式检查

已下载原件，大小3252字节，ASCII单行文本，无行终止符。
SHA256：`85259dfa97ce8e4174c2ec1aea502b7eb132af4c06cff278b12d3cd62a785ee1`。

文件起始为 `0024`，随后可分为24字符Base64片段（解码16字节）和其余Base64片段
（解码2416字节）。全文不是一个合法Base64块，更不是明文JSON、XML或QGC任务文本。
后段解码数据没有从文件头识别到常见压缩/容器格式，字节熵约7.922 bit/byte。
这些特征与编码/压缩/加密数据相容，但不能仅凭一个样本认定算法、密钥、
版本号含义或航点数量，也没有取得经纬度/高度等任务字段。

当前**不能宣称支持.ld导入**。用户确认软件只提供.ld，没有明文导出。
继续互操作验证需要格式说明，或该文件载入后的逐点属性作为独立对照；
CAAC自身格式仍以完整QGC plan JSON加版本化元数据设计。

## 可进一步复用的几何接口

构建依赖检查确认 QGC 已有 GeographicLib 2.7 和 `QGCGeoMath` 静态库。
`src/Utilities/Geo/QGCGeo.h/.cc` 已公开 `geodesicDistance`、`geodesicAzimuth`、
`geodesicDestination`，使用 WGS84 椭球；也有 LocalCartesian/NED 转换。
阶段三优先调用这些接口并检验返回值/高度语义，避免再引入同一几何依赖。
CAAC 几何层仍保留独立接口和测试；用户提供的球面模块用作对照，
不直接覆盖 QGC 已有椭球实现。
