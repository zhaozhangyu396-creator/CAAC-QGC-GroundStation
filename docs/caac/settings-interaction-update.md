# 设置与规划交互更新

本次改动在 `phase3/caac-route-geometry` 分支实现，面向 PX4。安装包与最终验证记录以本文件后续记录的提交及构件为准，旧版安装包不包含本次尚未打包的源码修改。

## 设置与显示

- 底部飞行数据栏的数值、标签与航向角字号略增并使用半粗体，窄窗口的数值适应可用宽度。顶部工具栏图标与字体增大约 15%，计时、连接、遥控器与数传状态增加间距，保留中间空白与右侧对齐。锁定状态使用实际飞控状态：上锁红色、解锁绿色。
- 取消设置侧栏的“主界面”，模拟／取消模拟置顶。同一项再次点击可收起二级菜单，点击其他项切换展开；收起保留左侧目录。
- 无人机设置目录按文字与图标所需宽度收窄。应用设置、分析在当前菜单内显示目录与详情并提供返回；保留原有参数、工具与弹出工具窗口功能。无人机设置与分析重新进入仍验证密码。
- 偏好采用统一侧栏样式。设置中的荧光绿装饰与选中态改为深灰和白色边框；实际飞行安全状态颜色保留。全局设置旋转、平移等分组的绿色竖线移除。
- 连接、RTK、应用设置采用与 RID 协调的深色分组、表单与按钮。串口页提供串口、波特率、连接／断开、刷新、自动连接，并保留“更多连接设置”的其他原生链路类型。
- RID 的“去填写”打开 UOM 注册标签，二者共享原有 UAS 编码设置。
- UOM 注册页面加入用户提供的实名登记、激活与所有者变更提示，默认显示有限高度的文字预览与渐隐遮罩；点击标题或底部箭头展开／收起全文，保留官网链接。

## 规划与飞行交互

- 新建或移动 H 点后，自动将位置和可用起飞点海拔应用到计划；地形数据返回后自动同步，保留手动海拔输入和真实净空告警。此处保存指应用计划起飞点，并非自动写入任务文件或上传飞控。
- 航点属性中的方位角、距离、微调弹窗改为鼠标左键双击打开；单击选择，右键功能菜单保留。
- 航点拖动使用实际指针移动更新位置，避免地图投影反向触发吸附计算；保留高度、吸附、撤销和重做。连续多点拖动的自动化验证不等同于已经复现并定位用户 Windows 崩溃的全部原因。
- 航线执行中上传被拦截，弹窗提示先暂停当前任务，再上传新航线。模拟与普通任务入口均检查，不会自动暂停、上传或恢复飞行。
- 统计数据面板支持左键拖动、右键菜单关闭，再次点击统计数据可打开。真高过低提示支持左键拖动并提高显示层级，避免被飞行操作面板遮挡。
- 左下地图工具条向上对齐清除航迹图标中心，小窗口保持在可见范围内；爬升设置紧接基础设置下方。

## 电池与电子围栏

- 电池保护采用 PX4 原生保护。低电量、严重低电量分区显示动作与 V 门限，可输入或使用加减按钮调整后确认写入原生参数。
- V 为按电池节数及满／空电压换算的等效整包参考电压：`节数 × [空电压 + (满电压 − 空电压) × 剩余电量阈值]`。飞控仍按原生剩余电量阈值触发；未配置电池节数时禁用换算设置，不编造默认电压。不支持的独立动作禁用，不通过地面站发送额外飞行指令实现保护。
- 电子围栏提供原生开关、主地图显示开关、绘制、读取、写入和真实地图预览。预览中通过原生顶点／边中点编辑围栏；使用 GeoFenceController 独立围栏协议传输。离线可绘制，传输受连接、能力与同步状态约束。
- UOM 正式平台上报尚未接通；实名登记与激活操作以官方平台为准。RID 广播、安全参数与实际飞行行为尚未进行 PX4 实机验收。
