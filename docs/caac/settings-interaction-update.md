# 设置与规划交互更新

后续调整见 [规划控件与飞行中航点更新](planning-controls-live-update.md)，其中包含移除访问密码与确认后自动暂停上传续飞的最新行为。

本次改动在 `phase3/caac-route-geometry` 分支实现，面向 PX4。安装包与最终验证记录见文末，本文件所列行为已包含在该安装包中。

## 设置与显示

- 底部飞行数据栏的数值、标签与航向角字号略增并使用半粗体，窄窗口的数值适应可用宽度。顶部工具栏图标与字体增大约 15%，计时、连接、遥控器与数传状态增加间距，保留中间空白与右侧对齐。锁定状态使用实际飞控状态：上锁红色、解锁绿色。
- 右上规划入口的四项文字增大；飞行操作面板八项文字统一字体、字号和白色亮度，按钮是否可用仍由原有飞行状态决定。
- 取消设置侧栏的“主界面”，模拟／取消模拟置顶。同一项再次点击可收起二级菜单，点击其他项切换展开；收起保留左侧目录。
- 无人机设置目录按文字与图标所需宽度收窄。应用设置、分析在当前菜单内显示目录与详情并提供返回；保留原有参数、工具与弹出工具窗口功能。无人机设置与分析入口已取消参数访问密码。
- 偏好采用统一侧栏样式。设置中的荧光绿装饰与选中态改为深灰和白色边框；实际飞行安全状态颜色保留。全局设置旋转、平移等分组的绿色竖线移除。
- 连接、RTK、应用设置采用与 RID 协调的深色分组、表单与按钮。串口页提供串口、波特率、连接／断开、刷新、自动连接，并保留“更多连接设置”的其他原生链路类型。
- RID 的“去填写”打开 UOM 注册标签，二者共享原有 UAS 编码设置。
- UOM 注册页面加入用户提供的实名登记、激活与所有者变更提示，默认显示有限高度的文字预览与渐隐遮罩；点击标题或底部箭头展开／收起全文，保留官网链接。

## 规划与飞行交互

- 新建或移动 H 点后，自动将位置和可用起飞点海拔应用到计划；地形数据返回后自动同步，保留手动海拔输入和真实净空告警。此处保存指应用计划起飞点，并非自动写入任务文件或上传飞控。
- 航点属性中的方位角、距离、微调弹窗改为鼠标左键双击打开；单击选择，右键功能菜单保留。Ctrl+Z 撤销，Ctrl+X 重做；文本输入框保留 Ctrl+X 剪切。
- 航点拖动使用实际指针移动更新位置，避免地图投影反向触发吸附计算；近重合辅助线按严格误差顺序排序，消除原先近似相等比较不满足排序约束的问题。保留高度、吸附、撤销和重做，增加模拟连接、五航点折线／闭合航线及连续快速拖动验证。自动化验证不等同于已经复现并定位用户 Windows 卡死的全部原因。
- 普通“上传航线”入口仍要求先暂停。飞行中拖动航点并确认更新，按“等待暂停 → 上传成功 → 恢复原目标 → 继续航线”执行；错误不自动续飞，详见后续更新文档。
- 统计数据面板支持左键拖动、右键菜单关闭，再次点击统计数据可打开。真高过低提示支持左键拖动并提高显示层级，避免被飞行操作面板遮挡。
- 地图竖向工具条位于清除航迹按钮和文字下方，与该图标中线水平对齐；小窗口可滚动访问。爬升设置紧接基础设置下方。

- 任务详情的“停留朝向”显示项替换为“剩余圈数”。有限循环按尚未完成的圈数显示（包含当前圈），暂停不递减；无限循环显示“无限循环”。模拟读取引擎实际循环次数，普通任务根据已上传／下载任务及飞控进度计算；中途重连或遥测中断导致有限圈数不可确定时显示未获取数据。

## 电池与电子围栏

- 电池保护采用 PX4 原生保护。低电量、严重低电量分区显示动作与 V 门限，可输入或使用加减按钮调整后确认写入原生参数。
- V 为按电池节数及满／空电压换算的等效整包参考电压：`节数 × [空电压 + (满电压 − 空电压) × 剩余电量阈值]`。飞控仍按原生剩余电量阈值触发；未配置电池节数时禁用换算设置，不编造默认电压。不支持的独立动作禁用，不通过地面站发送额外飞行指令实现保护。
- 电子围栏提供原生开关、主地图显示开关、绘制、读取、写入和真实地图预览。预览中通过原生顶点／边中点编辑围栏；使用 GeoFenceController 独立围栏协议传输。离线可绘制，传输受连接、能力与同步状态约束。
- UOM 正式平台上报尚未接通；实名登记与激活操作以官方平台为准。RID 广播、安全参数与实际飞行行为尚未进行 PX4 实机验收。

## USB 遥控器与模拟应急

1. 将遥控器以 USB 摇杆／游戏控制器方式连接电脑，在“无人机设置 → 操纵杆”选择设备，校准横滚、俯仰、偏航、油门四轴并启用。应在模拟飞机上锁时完成校准。
2. 开始内置模拟、上传航线并起飞，进入“模拟应急 → 模拟控制 → USB 遥控器通道映射”。通道监视显示 USB 原始轴值，CH1 对应第一个 USB 轴，不代表飞控接收机的 PWM 通道。
3. 选择三段开关对应的独立轴通道。默认低档为自动返航、中档为姿态模式、高档为航线任务；可调整各档位、两段／三段和反向。四个操纵轴不能兼作模式开关。修改配置会关闭模式映射，确认后再次启用。
4. 启用后先识别当前档位，随后拨动开关切换模式。首次连接、重连或修改配置不会根据静止开关位置自动恢复航线。模式映射保存在当前 USB 设备的原生 Settings Facts 中，仅控制本软件内置模拟飞机。
5. 中档使用摇杆控制倾斜、转向及升降，可手动飞回并降落。姿态训练保留水平惯性和风影响，不保持水平位置；油门中位保持高度。它是训练运动模型，不代表真实 PX4 飞控动力学。需要自动返航时拨到低档，切到高档可继续尚未完成的航线。
6. 摇杆输入中断超过 0.5 秒，模拟飞机悬停，不会持续执行最后一个摇杆输入；重新接入后须重新识别模式开关。也可在模拟控制中结束手动接管并悬停。
