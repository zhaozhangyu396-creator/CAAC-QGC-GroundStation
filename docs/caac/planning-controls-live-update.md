# 规划控件与飞行中航点更新

飞行中拖动普通航点后，地面站询问是否上传新位置。取消时保留本地编辑；确认后按以下顺序处理：

1. 请求暂停，并等待飞控报告暂停模式。
2. 记录暂停时的目标任务序号，上传更新后的任务并等待成功确认。
3. 恢复原目标任务序号，等待飞控回报，再恢复航线模式。

任务、连接或飞行器状态变化，以及上传或确认超时，都会取消自动续飞。更新期间阻止继续拖动或重复上传。普通“上传航线”按钮继续要求先暂停任务。

该流程用于航点位置变化。任务结构变化、无法确认的循环进度和复杂跳转任务需要暂停后手动上传。内置模拟保留当前位置、目标航点、停留进度、有效速度和循环计数；普通飞控的单个向后循环按已确认的剩余圈数续飞。

## 规划工具

- 单位换算新增经纬度，复用现有十进制度、度分秒和方向输入，校验经度 ±180°、纬度 ±90°。
- 计划起飞点与航点属性的度、分、秒同排显示，利用完整输入宽度；航点属性按位置、航段参数、高度与速度、高级设置分组。
- 地图空白处右键可清除本地航点，保留计划起飞点，支持撤销。
- 航点右键可设置任务结束时的降落点，替换原降落／返航结束项，支持撤销。内置模拟在全部循环完成后执行降落。

## 状态与设置

模拟任务详情显示执行中的有效速度和已上传的爬升方式，包含单航点覆盖设置。实机未提供的任务字段继续显示“未获取数据”，不以地面速度或离线默认值代替。

顶部“飞行设置”改为“航线飞行”，齿轮放大，连接及信号图标按实际宽度排列。“传感器状态”仅打开磁力计、陀螺仪、加速度计的小窗口，显示飞控实际报告的传感器。

设置标题竖条采用统一实心色；全局设置中已取消的竖条保持取消。飞行器偏好与单位分组上方增加横线，单位内部移除分隔线。绘图吸附设置使用一个边框，类似开关统一显示 ON／OFF。

地图竖向工具条置于“清除航迹”按钮与文字下方，按图标中线水平对齐；小窗口通过左侧滚动栏访问。取消无人机设置与分析入口的访问密码和修改密码功能。

## 验证范围

回归覆盖暂停确认先于上传、恢复目标序号、取消不上传、错误不续飞、循环及速度保留、降落点替换与撤销、右键清除、度分秒换算与布局、免密码页面访问。普通 MockLink 补充 PX4 暂停命令响应；测试仍需提供和核对飞控的任务序号回报。

测试与模拟验证不代替遥控器硬件和实机飞行验收。
