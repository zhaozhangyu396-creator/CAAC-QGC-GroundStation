# 凌动功能界面覆盖与统一布局实施清单

用户补充目标：覆盖凌动地面站全部功能界面，并重新设计相关 UI；功能区布局可参考凌动。
先交付本批中文修正、航点编辑和界面改版的 Windows 安装包，再分模块推进其余功能。
本清单是实现计划，不将未开发界面或 QGC 原有功能写成已完成的凌动等效实现。

## 菜单字号

按最新要求，普通菜单统一使用默认字号的 1.2 倍，原有大字号飞行模式标题在原字号基础上放大 1.2 倍，并继续跟随用户保存的界面缩放设置。
覆盖顶部菜单、设置页主/子导航、下拉与右键菜单、页面标签、飞行模式菜单和航线操作栏。
左侧工具栏按可见文字宽度扩展；航线操作栏的位置跟随左侧工具栏实际宽度，避免按钮重叠。
设置页长名称可换行，下拉菜单按当前字体重新计算内容宽度。

## 布局约定

参考已读取视频画面 `03-3`、`07-3`、`08-5`，采用地图居中的布局：

- 顶部：当前模式、飞行操作、连接与飞行器状态。
- 左侧：地图工具、视图、缩放、定位和测量。
- 右侧：编号航点列表、当前航点属性或当前工具的编辑面板。
- 底部：高度、速度、距离、航向及任务进度。
- 设置：按功能分类，统一中文术语、输入单位、确认和取消行为。

规划、飞行、仿真、教学和考试沿用上述结构。按窗口宽度和字体缩放布局；
保留 QGC 当前主题和可读性设置。使用本项目实现及 QGC 许可资源，不提取凌动图标或专有代码。
每个入口连接真实控制器和任务/训练状态；未实现的功能不放置假按钮或假执行结果。

### 单航点编辑补充截图

用户补充了“1 号航点”编辑页：基础设置依次为经度、纬度、高度、水平速度、垂直速度、方位角、相对距离；

经纬度旁切换按钮在十进制度与度分秒输入之间切换；截图同时展示两种格式。
格式切换只改变输入/显示形式，未编辑时应保留原坐标精度；保存时校验度分秒与经纬度范围，不使用截图数值覆盖现有航点。
垂直速度截图的单位 `m` 有误，项目界面应使用 `m/s`；高度、相对距离使用 `m`，角度使用 `°`。
高级设置沿用上表的动态字段规则，并排除已取消的“停止转弯”选项。
当前已实现的航点属性对话框不包含以上所有字段；度分秒切换、垂直速度和完整高级设置仍待实现。

这些选项的确认不代表已完成对应飞控语义。垂直速度不能直接当作现有水平速度设置：
QGC `SpeedSection::appendSectionItems` 当前生成地速/空速命令，
PX4 v1.16.0 [navigator_main.cpp](https://github.com/PX4/PX4-Autopilot/blob/v1.16.0/src/modules/navigator/navigator_main.cpp#L686)
的所读速度命令处理分支只根据 param2 设置 cruising speed。
这是官方源码分析，尚未做该固件的 SITL 或实机验证，不能据此声称垂直速度已生效。

分页圆点可点击，也可左右滑动；这是本项目选择的操作方式，不将其描述为已确认的凌动切页规则。
现已提供任务详情、飞行数据、地图设置和单次居中四个入口。前三个面板独立开关，可同时堆叠，内容超过可用高度时滚动。这是本项目采用的组合规则。
源码接口与实现状态如下：

- 飞行时间、海拔高度、空速：`VehicleFactGroup` 中已注册的 `flightTime`、`altitudeAMSL`、`airSpeed` Facts。
- 卫星数：本阶段使用主 GPS 的 `VehicleGPSFactGroup::count`，无有效值时显示未获取数据。
- 无人机居中：原生 `CenterMapDropButton.qml` 已有将地图中心设为活动飞行器坐标的动作；可在自定义准星按钮中复用。
  无活动飞行器或无有效位置时禁用准星按钮；不改变持续跟随设置。
- 锁定飞机：现有飞行地图绑定 `flyViewSettings.keepMapCenteredOnVehicle`；与凌动行为是否完全等效仍待确认。
- 飞行日志：`Vehicle` 提供 `formattedMessages`、`newFormattedMessage` 和 `textMessageReceived`，原生 `VehicleMessageList.qml` 已展示消息。
  新日志页沿用 QGC 的时间、来源和原始消息格式，支持滚动，监听 `newFormattedMessage` 实时更新；切换活动飞行器时载入对应消息历史。
  截图中的实际日志来源尚未证实，不能假定 PX4 会发送同样文本。
  中文展示可将截图中已识别的 CondYaw、Delay、ChangeSpeed、WP 分别表述为偏航条件、延时、速度调整、航点，
  将“Delaying 4 sec”展示为“等待 4 秒”，保留原始消息与任务编号以便核对；上述日志中文解释尚未增加，目前展示原始消息。
- 四向里程：按用户确认的位移分量规则实现独立统计，不由总里程、相对起飞点净位移或截图数值推算。
  飞行状态采用 `Vehicle::airborne`，区别于仅解锁；每架飞行器独立保存，切换活动飞行器不清零。
  模拟重新开始的清零接口单独提供；尚无本项目模拟重启控制流程，不能把接口测试写成已接入模拟功能。
- 双击加点与拖拽航点：地图设置已提供两个独立持久化开关，接入 CAAC 规划地图的双击加点和左键拖点；禁用拖点仍可选中航点和右键编辑属性。
- 目标航点：复用任务执行状态与 QGC 任务模型；必须区分当前执行目标和规划页选中项，任务编号与地图保持一致。
- 航点速度、目标高度来自任务设定；海拔高度、空速来自遥测，两类字段分别取值。
  目标高度应明确现有高度基准；空速保持空速含义，并可另设地速显示。
- 没有活动飞行器或有效数据时提供未取得数据状态，不用截图示例值填充；不指定停留朝向保留为独立状态。

“航线朝向：默认”对应的实际模式、停留朝向“—”的具体含义，以及任务详情取本地计划还是飞控正在执行的任务，
仍需结合操作说明核对。编辑本地航点和上传任务分别使用原有 QGC 流程。
本批新增真实面板和交互开关，验证结果单独记录；截图登记不计为测试通过。

## 模块与文件方向

当前规划代码位于 `custom/src/PlanView/` 和 `custom/src/Route/`，
通过 `CaacCorePlugin` 挂接 `MissionController` / `PlanMasterController`。
此次改版继续使用该入口；原任务树通过“任务参数”切换，围栏和集结点保持原生编辑。

后续按模块新增，而不一次性替换 QGC：

| 模块 | 建议文件 | 复用对象 |
| --- | --- | --- |
| 飞行操作与遥测布局 | `custom/src/FlyView/CaacFlightPanel.qml` | `FlyView`、`GuidedActionsController`、`Vehicle` |
| 航点批量管理与工具 | `custom/src/PlanView/CaacWaypointList.qml`、`CaacMeasureTool.qml` | 当前航点控制器和 WGS84 几何接口 |
| 全局设置 | `custom/src/PlanView/CaacGlobalSettings.qml` | QGC Facts、任务设置项、当前 WGS84 控制器；飞控行为单独验证 |
| 模板规划 | `custom/src/Route/CaacRouteTemplates.h/.cc`、`custom/src/PlanView/CaacTemplateEditor.qml` | QGC 简单任务项、当前撤销事务 |
| 仿真训练 | `custom/src/Training/CaacSimulationController.h/.cc`、`CaacSimulationPanel.qml` | PX4 SITL、QGC 连接管理和 Vehicle |
| 考试流程 | `custom/src/Exam/CaacExamController.h/.cc`、`CaacExamPanel.qml` | 当前任务模型、版本化航线文件、操作日志 |
| 课程与训练记录 | `custom/src/Training/CaacTrainingController.h/.cc`、`CaacTrainingPanel.qml` | 考试/训练结果与本地记录 |

文件名为设计方向，以上尚未创建的文件不代表实现交付。
每个模块先核对输入、状态、真实动作和失败处理，再编译、测试并提供 Windows 验证包。
实机飞行、SITL、UOM 接入及正式考试规则的验收分别记录，不能由界面或 MockLink 测试替代。
