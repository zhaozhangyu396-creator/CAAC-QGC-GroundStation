# 凌动功能界面覆盖与统一布局实施清单

用户补充目标：覆盖凌动地面站全部功能界面，并重新设计相关 UI；功能区布局可参考凌动。
先交付本批中文修正、航点编辑和界面改版的 Windows 安装包，再分模块推进其余功能。
本清单是实现计划，不将未开发界面或 QGC 原有功能写成已完成的凌动等效实现。

## 布局约定

参考已读取视频画面 `03-3`、`07-3`、`08-5`，采用地图居中的布局：

- 顶部：当前模式、飞行操作、连接与飞行器状态。
- 左侧：地图工具、视图、缩放、定位和测量。
- 右侧：编号航点列表、当前航点属性或当前工具的编辑面板。
- 底部：高度、速度、距离、航向及任务进度。
- 设置：按功能分类，统一中文术语、输入单位、确认和取消行为。

规划、飞行、仿真、教学和考试沿用上述结构。按窗口宽度和字体缩放布局；
保留 QGC 当前主题和可读性设置。使用本项目实现及 QGC 许可资源，不提取凌动图标或专有代码。
每个入口连接真实控制器和任务/训练状态；未实现的功能不放置假按钮或假执行结果。

## 当前资料范围

已读取十段操作视频的 60 张采样帧，并取得用户对鼠标、夹角、旋转、撤销和文件保存的说明。
详见 [参考资料分析](reference-review.md)。采样画面不代表已穷尽软件全部页面。
凌动安装程序和完整 ZIP 仍超过下载工具 32 MiB 上限，未运行或解包分析；`.ld` 尚未解码。
用户另提供了全局设置、相对坐标编辑器、四种模板、六边形选项及精准移动的截图。已登记布局和字段，
截图不能确定的选项、基准位置、生成顺序及飞控行为仍待用户说明。

截图确认右侧四个入口为：全局设置、相对坐标、模板编辑器、航点列表。
相对坐标页面采用基础设置（基准点、角度类型、角度数值、相对距离）、
高级设置（生成方式、插入位置）和底部添加按钮，并提示空格键加点。

全局设置包括：起飞点经纬度和高度；航点高度、水平速度、垂直速度；
转弯和爬升方式；闭合航线和循环行为；结束行为、返航点和起始点；
两点定向旋转的两个点、目标方位角和旋转中心；平移方式、参考点、目标经纬度及航线拖拽。
截图当前选值分别是协调转弯、协调爬升、否、不循环、返航、起飞点、指定经纬度、禁用。
用户已确认以下选项，飞行语义仍需逐项核对：

- 转弯方式：停止转弯、定点转弯、协调转弯、自适应协调转弯、不转弯。
- 爬升方式：定点爬升、协调爬升。
- 循环行为：不循环、指定循环次数、循环。
- 结束行为：就地悬停、返航。
- 返航点、起始点：起飞点及现有航点。
- 平移方式：指定经纬度、精准移动。精准移动输入角度数值和相对距离。
- 航线拖拽启用时，以左键拖动整条航线，起飞点和降落点一起移动。

这些选项的确认不代表已完成对应飞控语义。垂直速度不能直接当作现有水平速度设置：
QGC `SpeedSection::appendSectionItems` 当前生成地速/空速命令，
PX4 v1.16.0 [navigator_main.cpp](https://github.com/PX4/PX4-Autopilot/blob/v1.16.0/src/modules/navigator/navigator_main.cpp#L686)
的所读速度命令处理分支只根据 param2 设置 cruising speed。
这是官方源码分析，尚未做该固件的 SITL 或实机验证，不能据此声称垂直速度已生效。

模板字段确认如下，用户已确认：圆形基准为圆心；六边形基准为所选 A～F 顶点；弓形基准为所选起始角；
星形采用五角星交叉航线，以首个顶点为基准；生成后插在基准点之后。
初始朝向、是否重复首点闭合、是否重复已有起点等细节仍在询问，实际生成功能尚未实现：

| 模板 | 字段与截图当前值 | 待确认规则 |
| --- | --- | --- |
| 圆形 | 基准点、直径 100 m、航点数量 10、顺时针 | 首点方位、是否闭合 |
| 六边形 | 基准点、边长 100 m、横边置顶、起始点 A；预览标记 A～F | 类型已确认横边置顶/点置顶，起始点 A～F；生成顺序、是否闭合 |

## 模块与文件方向

当前规划代码位于 `custom/src/PlanView/` 和 `custom/src/Route/`，
通过 `CaacCorePlugin` 挂接 `MissionController` / `PlanMasterController`。
此次改版继续使用该入口；原任务树通过“任务参数”切换，围栏和集结点保持原生编辑。

后续按模块新增，而不一次性替换 QGC：

| 模块 | 建议文件 | 复用对象 |
| --- | --- | --- |
| 飞行操作与遥测布局 | `custom/src/FlyView/CaacFlightPanel.qml` | `FlyView`、`GuidedActionsController`、`Vehicle` |
| 航点批量管理与工具 | `custom/src/PlanView/CaacWaypointList.qml`、`CaacMeasureTool.qml` | 当前航点控制器和 WGS84 几何接口 |
| 全局设置 | `custom/src/PlanView/CaacGlobalSettings.qml` | QGC Facts、任务设置项、当前 WGS84 控制器；飞控行为单独验证 |
| 模板规划 | `custom/src/Route/CaacRouteTemplates.h/.cc`、`custom/src/PlanView/CaacTemplateEditor.qml` | QGC 简单任务项、当前撤销事务 |
| 仿真训练 | `custom/src/Training/CaacSimulationController.h/.cc`、`CaacSimulationPanel.qml` | PX4 SITL、QGC 连接管理和 Vehicle |
| 考试流程 | `custom/src/Exam/CaacExamController.h/.cc`、`CaacExamPanel.qml` | 当前任务模型、版本化航线文件、操作日志 |
| 课程与训练记录 | `custom/src/Training/CaacTrainingController.h/.cc`、`CaacTrainingPanel.qml` | 考试/训练结果与本地记录 |

文件名为设计方向，以上尚未创建的文件不代表实现交付。
每个模块先核对输入、状态、真实动作和失败处理，再编译、测试并提供 Windows 验证包。
实机飞行、SITL、UOM 接入及正式考试规则的验收分别记录，不能由界面或 MockLink 测试替代。
