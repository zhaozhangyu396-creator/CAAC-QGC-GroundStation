# 简体中文离线词库

`qgc_source_zh_CN.ts` 和 `qgc_json_zh_CN.ts` 包含界面、设置和提示消息译文。
`qgc_parameters_0_zh_CN.ts` 至 `qgc_parameters_7_zh_CN.ts` 包含 15,582 条去重的参数说明和选项，按源文本排序后分为八份，随安装包编译为 Qt 翻译资源。另提供换行归一化及索引展开的兼容条目。

参数词库覆盖本次构建内置的 PX4 参数元数据、模拟器参数元数据，以及实际打包的 38 份 ArduPilot 参数定义文件。
来源为公开的 PX4/QGroundControl 元数据和 ArduPilot ParameterRepository 提交 `d547bf2e786f2fa53f6744da93252e5ce1567553`。
原始 PX4 和模拟器元数据对应本仓库提交 `197e752212e75d6cd863030eabd8353c4d67f0ac`。

新增大批量参数译文以公开参考资料的机器翻译为基础，补充了人工术语修订和特殊段落译文。
参数名称、参数实际数值和选项顺序保持原有定义；品牌、协议、引脚名称及单位保留必要的英文标识。
参数编辑窗口提供“显示英文原文”，便于核对技术说明。

`VehicleMessageTranslatorTest` 逐条核对编译词库与 TS 文本、长说明中的参数标识以及本地化切换。
翻译占位符仍由项目现有的 `qt-translation-placeholders` 检查验证。
更新固件参数定义后，应重新核对新增源文本，更新对应译文及覆盖数量。

本地消息词库未收录的新英文消息可通过 MyMemory 公共服务异步补充翻译。
“常规”设置提供在线翻译开关；公共服务不可用时显示原文。
在线译文附带标记及原文，原始协议消息不参与改写。
